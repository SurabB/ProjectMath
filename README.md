# Basic Numerical Math Library

A Java library that provides implementations of common numerical methods such as root finding, interpolation, matrix operations, and other computational techniques.

## Features

* Root finding algorithms
* Interpolation methods
* Matrix operations
* Numerical utilities

## Installation

This project can be used as a dependency in projects built with **Apache Maven**.

### Step 1: Add Repository

Add the repository to your `pom.xml`:

```xml
<repositories>
    <repository>
        <id>github</id>
        <url>https://maven.pkg.github.com/SurabB/ProjectMath</url>
    </repository>
</repositories>
```

### Step 2: Add Dependency

```xml
<dependency>
    <groupId>io.github.SurabB</groupId>
    <artifactId>project-math</artifactId>
    <version>2.0.0</version>
</dependency>

```
