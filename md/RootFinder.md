# RootFinder

**Location**

```
src/main/java/project/sb/Math/RootFinder.java
```

`RootFinder` is a utility class that provides numerical methods to compute **roots of non-linear equations**.

Supported algorithms:

- Newton–Raphson Method
- Bisection Method
- Secant Method

All methods in this class are **static**, so the class can be used without creating an object.

---

# Mathematical Problem

We want to find a value of **x** such that

f(x) = 0

For example

x³ − x − 1 = 0

A value of **x** that satisfies this equation is called a **root**.

---

# Internal Structure

## Seed (Static Inner Class)

`Seed` is a **static inner class** that acts as a container for the **initial guesses** required by root-finding algorithms.

Most numerical methods require two starting points:

x<sub>0</sub> , x<sub>1</sub>

These values are stored inside a `Seed` object and passed to the solving methods.

---

# Methods

---

# getSeed()

Computes **initial guesses** automatically within a given interval.

The method scans the interval `[start , end]` using a step size and tries to detect **sign change**:

f(a) × f(b) < 0

If a sign change occurs, the interval contains a root.

---

## Parameters

| Parameter | Type | Description |
|----------|------|-------------|
| `start` | `double` | starting point of search interval |
| `end` | `double` | ending point of search interval |
| `steps` | `double` | step size (jump between guesses) |
| `f` | `Function<Double,Double>` | equation f(x) whose root is required |

---

## Returns

```
Optional<Seed>
```

Possible outcomes:

- `Optional.empty()` → no suitable guesses found
- `Optional<Seed>` → contains initial guesses

The returned `Seed` object contains

x<sub>0</sub> , x<sub>1</sub>

---

# newtonRaphson()

Computes the root using the **Newton–Raphson method**.

### Formula

x<sub>n+1</sub> = x<sub>n</sub> − f(x<sub>n</sub>) / f′(x<sub>n</sub>)

Where

- f(x) is the equation
- f′(x) is its derivative

The iteration continues until

|x<sub>n+1</sub> − x<sub>n</sub>| < eps  or maxIteration

---

## Parameters

| Parameter | Type | Description |
|----------|------|-------------|
| `seed` | `Seed` | initial guess container (generated by `getSeed()`) |
| `fDerivative` | `Function<Double,Double>` | derivative of the equation |
| `eps` | `double` | precision required |

---

## Returns

```
double
```

The **computed root** of the equation.

---

# bisection()

Computes the root using the **Bisection Method**.

This method repeatedly halves the interval containing the root.

### Condition

f(a) × f(b) < 0

### Iteration

mid = (a + b) / 2

If

f(a) × f(mid) < 0

then

b = mid

else

a = mid

This continues until the interval size becomes smaller than the required precision or maxIteration.

---

## Parameters

| Parameter | Type | Description |
|----------|------|-------------|
| `seed` | `Seed` | initial guesses |
| `eps` | `double` | precision required |

---

## Returns

```
double
```

Approximate root.

---

# secant()

Computes the root using the **Secant Method**.

This method approximates the derivative using two points.

### Formula

x<sub>n+1</sub> = x<sub>n</sub> − f(x<sub>n</sub>) (x<sub>n</sub> − x<sub>n−1</sub>) / ( f(x<sub>n</sub>) − f(x<sub>n−1</sub>) )

The iteration continues until

|x<sub>n+1</sub> − x<sub>n</sub>| < eps or max Iteration.

---

## Parameters

| Parameter | Type | Description |
|----------|------|-------------|
| `seed` | `Seed` | initial guesses |
| `eps` | `double` | precision required |

---

## Returns

```
double
```

Approximate root.

---

# Example

```java
public static void main(String[] args) {

    Seed seed = RootFinder
            .getSeed(-10, 1000, 1, x -> Math.pow(x, 3) - x - 1)
            .get();

    double n = RootFinder.newtonRaphson(
            seed,
            x -> 3 * Math.pow(x, 2) - 1,
            0.0001
    );

    double b = RootFinder.bisection(seed, 0.0001);

    double s = RootFinder.secant(seed, 0.0001);

    System.out.println(n);
    System.out.println(b);
    System.out.println(s);
}
```

# Methods Summary

| Method | Order of Convergence | Requires Derivative |
|------|------|------|
| Newton–Raphson | Quadratic (fastest) | Yes |
| Secant | Superlinear | No |
| Bisection | Linear (slowest but safest) | No |

---

# Notes

- `getSeed() :` helps automatically detect a valid interval containing a root.
- `Optional<Seed> :` ensures **safe handling when no root interval is found**.
- Precision is controlled using the parameter `eps`.

---

# Suggestion

Always check:

```
Optional<Seed> seedOpt = RootFinder.getSeed(...);

if(seedOpt.isPresent()) {
    Seed seed = seedOpt.get();
}
```

instead of calling `.get()` directly.
